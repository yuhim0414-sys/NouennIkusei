# まなび農園 6年生のぼうけん

問題に正解して水をため、野菜を育てて売り、農園を広げていく学習ゲームです。
子どもが考えたゲームの案をもとに作りました。

## 遊び方

1. 畑の「たねをまく」をおして、作物をえらぶ
2. 下の「水をゲット」をおして、教科と単元をえらび、問題をとく
3. 1問正解すると、水が1こもらえる（今日のおすすめの教科は2ばい）
4. 畑をおして水をあげる。育ったら「しゅうかく！」をおす
5. 「ぜんぶ売る」でコインにかえて、たね・畑・新しい場所の開放に使う

## 収録している問題（小学6年生）

- 算数：12単元（図の問題、電卓、手書きの計算メモつき）
- 国語：漢字の読み 約550語、書き 約80問
- 理科：9単元
- 社会：11単元
- まちがえた問題は「苦手な問題」にたまり、あとでまとめて挑戦できる
- まちがえたときは解説を表示

## GitHub Pages で公開する手順

1. GitHub で新しいリポジトリを作る（Public）
2. このフォルダの中身（`index.html`、`.nojekyll`、`README.md`）をアップロードする
3. リポジトリの Settings → Pages を開く
4. 「Branch」で `main` と `/ (root)` をえらんで Save
5. 1〜2分待つと `https://ユーザー名.github.io/リポジトリ名/` で開けるようになる

## 知っておくこと

- ファイルは `index.html` 1つだけで動きます。サーバー側の処理はありません。
- セーブデータは、遊んだ端末のブラウザ（localStorage）に保存されます。別の端末やブラウザには引きつがれません。
- 文字の書体だけ Google Fonts から読み込みます。ネットにつながらない場合は端末の標準の書体で表示されます。
- 音は、最初に画面をおしたあとから鳴ります。右上の🔊で消せます。
- 端末の「視差効果を減らす」設定がオンのときは、動きのある演出を自動で止めます。
- 右上の⚙️に、先生用のレベル変更とデータの初期化があります。

## 数値の調整

`index.html` の `<script>` の先頭付近にまとめてあります。

| 変えたいもの | 場所 |
|---|---|
| 場所の必要レベルと開放の値段 | `AREAS` |
| レベルアップに必要な経験値 | `need` |
| 作物のねだん・必要な水 | `CROPS` |
| 同じ単元の1日の上限 | `capOf` |
| 理科・社会の問題と解説 | `FIXQ` と `EXPL` |
| 漢字 | `YOMI` と `KAKI` |
